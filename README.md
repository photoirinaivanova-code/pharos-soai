# Pharos Season of AI — чтение ончейн-данных и мониторинг событий

Готовое **только читающее** решение уровня Easy для [Pharos Season of AI](https://www.pharos.xyz/blog/introducing-pharos-season-of-ai-build-for-the-agentic-economy): инструмент на Python 3, который через официальный публичный RPC тестовой сети Atlantic запрашивает блоки, балансы, транзакции, сведения об ERC-20 и события `Transfer`, а также умеет следить за новыми переводами с фильтром по адресу и порогу суммы.

Инструмент **не умеет** подписывать транзакции, не принимает приватные ключи и seed-фразы и не подключается к кошельку. Нужны только публичные адреса и хеши транзакций.

Официальный текст конкретного задания на доске после регистрации в открытом доступе не опубликован. Сверьте этот репозиторий с формулировкой на доске заданий, прежде чем отправлять работу.

## Как это соотносится с заданием Easy

Официальный блог описывает входные задания как «reading onchain data» и «monitoring events», а в тулките сезона назван Chain MCP. Этот проект:

1. Повторяет чтение тех же JSON-RPC методов, что документированы у Pharos MCP, но на тестовой сети Atlantic.
2. Добавляет удобную расшифровку ERC-20 (`name`, `symbol`, `decimals`, `balanceOf`) и событий `Transfer`.
3. Даёт простой монитор: опрос новых блоков, печать совпавших переводов, фильтр по адресу и порогу (`--min-value`).
4. Упакован как скилл в каталоге `skill/` в официальной структуре Skill Engine, но **без** операций записи и без Foundry/`PRIVATE_KEY`. Официальный Skill Engine как раз умеет отправлять транзакции через `cast send`; здесь это сознательно исключено.

## Требования

- macOS с установленным Python 3.10 или новее (`python3 --version`)
- доступ в интернет к `https://atlantic.dplabs-internal.com`
- ничего больше: зависимость одна — `requests==2.32.5`

## Установка на macOS

```bash
# 1. Распакуйте архив или склонируйте репозиторий, затем:
cd pharos-soai

# 2. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# 3. Зависимости и установка пакета в это окружение
python3 -m pip install --upgrade pip
python3 -m pip install -e .
python3 -m pip install -r requirements-dev.txt   # только если будете гонять тесты
```

Если не хотите делать `pip install -e .`, перед командами задайте `export PYTHONPATH=src`.

Если `python3` не найден, установите Python с [python.org](https://www.python.org/downloads/) или через Homebrew: `brew install python`. Ставьте только официальный интерпретатор, не скачивайте «крипто-утилиты» со сторонних сайтов.

## Примеры использования

Все команды печатают JSON в стандартный вывод.

```bash
# Проверка сети: chainId должен быть 688689
python3 -m pharos_soai chain

# Последний блок
python3 -m pharos_soai block latest

# Баланс любого публичного адреса (пример — нулевой адрес)
python3 -m pharos_soai balance 0x0000000000000000000000000000000000000000

# Детали транзакции и квитанция (подставьте реальный хеш из обозревателя)
python3 -m pharos_soai tx 0xВАШ_ХЕШ
python3 -m pharos_soai receipt 0xВАШ_ХЕШ

# Официальный USDC тестовой сети
python3 -m pharos_soai token 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B
python3 -m pharos_soai token-balance 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B 0xАДРЕС_ДЕРЖАТЕЛЯ

# Недавние Transfer (по умолчанию последние ~200 блоков)
python3 -m pharos_soai transfers 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B --limit 10

# Однократный мониторинг с фильтром: адрес участвует в переводе и сумма >= 1 USDC (6 знаков)
python3 -m pharos_soai monitor 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B \
  --watch 0xАДРЕС \
  --min-value 1000000 \
  --lookback 50 \
  --once
```

Список официальных токенов тестовой сети:

```bash
python3 -m pharos_soai tokens
```

Параметр `--rpc` позволяет указать другой URL, но по умолчанию используется официальный публичный RPC Atlantic. Не вставляйте в команды ключи и не добавляйте флаги вроде `--private-key`: программа их отвергнет.

Лимит публичного RPC: 500 запросов за 5 минут ([документация сети](https://docs.pharos.xyz/getting-started/network/atlantic-testnet)). Не гоняйте монитор слишком часто.

## Скилл для агента

Каталог `skill/` повторяет официальный каркас Skill Engine:

- `skill/SKILL.md` — входная точка и индекс возможностей
- `skill/assets/networks.json` и `skill/assets/tokens.json`
- `skill/references/query.md` и `skill/references/monitor.md`

Агент должен сначала прочитать `SKILL.md`. Операций записи нет.

## Сценарий демо-видео на 1–2 минуты (+50 очков за видео, по правилам сезона)

1. Покажите страницу [официального блога сезона](https://www.pharos.xyz/blog/introducing-pharos-season-of-ai-build-for-the-agentic-economy) и скажите, что это решение уровня Easy: чтение данных и мониторинг событий на Atlantic Testnet.

3. Выполните `python3 -m pharos_soai token 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B` и коротко поясните, что это официальный USDC из реестра токенов.
4. Выполните `python3 -m pharos_soai transfers 0xcfC8330f4BCAB529c625D12781b1C19466A9Fc8B --limit 5`. Если события есть, откройте `explorer` из JSON в [atlantic.pharosscan.xyz](https://atlantic.pharosscan.xyz/). Если список пустой, честно скажите, что за выбранный диапазон переводов не было.

6. Покажите файл `skill/SKILL.md` и подчеркните: ключи не используются, транзакции не подписываются.
7. Завершите указанием ссылки на ваш GitHub-репозиторий.

Запись лучше вести в QuickTime (Файл → Новая запись экрана) около 90 секунд. Как именно организаторы просят публиковать видео (X, YouTube и т.д.), смотрите на доске заданий: в открытом блоге сказано только «video recording or walkthrough shared on social media».
